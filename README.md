# Projeto de HTML - Honkai: Star Rail

Esse aqui é o meu projeto da matéria de Desenvolvimento Front-End para Web. Escolhi o tema de Honkai: Star Rail e fiz um site completo tipo um banco de dados do jogo. Como se fosse os próprios personagens do expresso astral recrutando e mostrando o universo deles.

O objetivo da atividade era criar um site com mais de 10 páginas usando APENAS HTML puro (sem usar nada de CSS pra estilizar e sem JavaScript).
