Honkai: Star Rail — Arquivos do Expresso

Este projeto é um guia web interativo e informativo sobre o universo de Honkai: Star Rail, desenvolvido como uma atividade prática de HTML Avançado. 

O objetivo principal do projeto é construir uma aplicação web com mais de 10 páginas aplicando conceitos modernos de estruturação semântica, multimídia, formulários e elementos interativos, utilizando exclusivamente HTML5 puro (sem CSS e sem JavaScript).
